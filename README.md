# ffl_calendar · 海航 PLUS 航线查询工具

这是一个直接读取 `data/flights.db` SQLite 数据库的网页工具，使用 Python 标准库实现，**不需要 pip 安装任何第三方包**。

## 已实现

- 单程 / 往返
- 直飞 / 最多 1 次中转 / 最多 2 次中转
- 会员筛选默认 666，可切换 666/2666（全部）
- 出发 / 到达机场支持输入搜索，不再使用超长下拉框
- 机场选择器支持 A-Z 首字母索引，按城市中文拼音首字母分组
- 航司、航班号筛选；航线总览支持周一至周日筛选
- 起飞、到达、总行程时间、中转次数排序
- 到达跨天 `+1`
- 航司、航班号、机型、起降时刻、产品展示
- 航线总览：按出发机场查看整个数据周期的全部目的地、航班号、时刻、班期、运行天数
- 城市级航线总览：输入北京、上海、成都等城市时，自动合并该城市多个机场，并按目的城市汇总
- 航线总览时刻容错：同一航班号 30 分钟内的轻微计划调整自动合并，展示出现次数最多的主时刻
- 手机 / PC 响应式页面

## PLUS 规则

按当前约定：

- **666**：08:00 前，或 20:00 后出发
- **2666**：覆盖全天

所以早晚时段显示 `666/2666`，其余显示 `2666`。

## macOS 启动

最简单：双击 `start.command`。

或终端：

```bash
cd hna_plus_web
python3 app.py
```

然后打开：

```text
http://127.0.0.1:5000
```

让同一 Wi‑Fi 下的手机访问：

```bash
python3 app.py --host 0.0.0.0 --port 5000
```

再用手机访问 Mac 的局域网 IP，例如 `http://192.168.1.10:5000`。

## 更新航班数据

运行时数据使用 SQLite：

```text
data/flights.db
```

拿到新的 `flight_daily.csv` 后执行：

```bash
python3 scripts/import_csv_to_sqlite.py /path/to/flight_daily.csv data/flights.db
```

生成新的数据库后提交 `data/flights.db`。生产运行不再读取 CSV。

## v4 修复

- 修复点击“热门 / ABCDEF / GHIJ / KLMN / PQRSTUV / WXYZ”标签后城市选择面板自动关闭的问题。
- 原因是标签切换时会重绘标签 DOM，点击事件继续冒泡后被外层误判为点击弹层外部。

## 数据库日历状态

本版只调整“航线总览 → 查看具体日期”的日历数据来源与颜色，页面其他布局和交互保持上一版不变。

- 绿色：航班运行，且该日期有/有过 B 舱（包含当前可见或规则上应有但当前已隐藏/售罄）。
- 橙色：航班运行，但所选会员规则下不计 B 舱（例如节假日或时段过滤）。
- 灰色：航线首末出现区间内，当天数据库没有航班运行记录。
- 虚线浅灰：航线首末出现日期之外。

日历不显示余票数量。


## 总览时刻容错

航线总览不会再把同一航班号每天 5～30 分钟的小幅计划调整全部列出来。

处理方式：

- 先按航班号分组。
- 完全相同的起飞 / 到达时刻统计出现次数。
- 起飞和到达时刻都在 **30 分钟**以内的变化视为同一时刻簇。
- 每个时刻簇只展示出现次数最多的主时刻。
- 如果同一航班号确实存在相差超过 30 分钟的明显换季时段，则仍保留为独立时刻。
- 单日航班搜索仍显示数据库中当天的真实起降时刻，不做合并。

例如 `PEK → HGH` 当前数据会将 HU7177 的 `21:00 / 21:25 / 21:30` 等轻微变化合并为主时刻 `21:00 → 23:20`。
